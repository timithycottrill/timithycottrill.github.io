Data practices

Privacy policy

Effective October 26, 2026 · Application: AI YouTube Studio Automation

This policy describes the privately operated creator automation installation maintained by the GitHub account timithycottrill. It covers its use of Google APIs and this informational website.

Information accessed

  • Google authorization: OAuth access and refresh tokens and connection configuration needed to maintain an authorized API session. The application does not receive your Google password.
  • YouTube: authorized channel identifiers and channel information; selected videos’ metadata and status; playlist membership; and upload identifiers, processing results, or other information returned by enabled content-management operations.
  • Google Sheets: selected review-queue rows, including titles, descriptions, approvals, job references, and publication status. Configured workflows may update those rows.
  • Google Drive and Docs: selected file metadata, document text, or file contents needed by a workflow that the operator connects and authorizes.
  • Local production: selected media, scripts, transcripts, generated narration, thumbnails, render artifacts, checksums, job records, and operational logs.

The actual access available depends on the Google permissions granted and the enabled workflow. This installation is for the operator’s accounts and specifically authorized collaborators, not an open consumer service.

How information is used

Information is used to organize media production, prepare scripts and selected assets, process and review videos, publish or update approved content on authorized accounts, prevent duplicate uploads, and reconcile publication results. It is not sold, used for targeted advertising, or provided to data brokers.

Storage and access

Production data is kept in the operator-controlled PC, self-hosted n8n storage, local worker storage, designated external drives, and any backups the operator configures. Credentials are kept in n8n’s credential storage or separate private configuration files; they are not part of this public website or its repository. Access is limited to the operator and explicitly authorized services or collaborators. API communication uses HTTPS. No claim is made that every local media file or backup is encrypted.

Sharing and connected services

Google receives API requests needed to provide the connected Google services. When the operator publishes, the selected video and approved metadata are sent to the chosen destination platform and may become public according to the selected visibility. n8n and local media workers process data for the configured workflow. Other social platforms, campaign services, or AI providers receive selected content only when the operator explicitly enables and authorizes that integration; private Google data must not be sent to an additional provider without disclosure and authorization for that purpose.

Google API user data is not used to develop, improve, or train generalized AI or machine-learning models. Human access is limited to the operator’s authorized review, support or security needs, or applicable legal requirements.

Google API Limited Use

AI YouTube Studio Automation’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, revocation, and deletion

The operator controls retention of source media, working files, final exports, and audit records. Files remain until removed under the applicable workflow or backup policy; there is no universal automatic deletion period. Disconnecting or revoking a Google authorization stops future authorized access after the connection is invalidated, but does not automatically delete previously saved local files or content already published to a platform.

Revoke access through Google Account connections. Delete the corresponding saved credential and production records from the operator-controlled installation when no longer needed. Content on YouTube or another destination must be removed there separately. For assistance or a deletion request, contact the operator through the repository support link below. Do not include tokens, private documents, or other confidential information in a public issue.

This website

These static pages contain no application login, advertising scripts, analytics scripts, or tracking pixels. Hosting is provided by GitHub Pages; GitHub may process routine connection and hosting information under its privacy statement. External links are governed by their providers’ policies.

Updates and contact

This policy will be updated when data practices change. New uses of Google data require an updated disclosure and any necessary authorization before that use begins. Support and privacy questions can be raised through the operator’s support repository. For private matters, request a private contact method without posting confidential details.
